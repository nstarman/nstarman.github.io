# Research

- **Decision**: a per-section map `runSize`, as `tally` and `refereed` are. **Rationale**: a CV may hold more than one publication list. **Alternatives**: a global setting — fewer keys, but the only per-list heading control would then be global.
- **Decision**: a multiple of the body size, 0.8–2. **Rationale**: follows each style's type size, as the `x` spacing unit does. **Alternatives**: points — breaks across styles.
